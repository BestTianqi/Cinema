# 视觉设计文档

本文档说明 SmartCinema 的整体视觉风格、色彩方案、布局与字体选择，以及背后的设计考量。

---

## 一、设计风格定位

**关键词**：深色科技感、沉浸式、克制、信息清晰。

整体定位参考了 Apple（极简与留白）、Tesla（深色科技感）、OpenAI（现代克制）的视觉语言，但做了一个关键调整——**因为这是影院选座系统，主背景模拟了真实影院的暗场环境**，让用户在选座时就有"进入影厅"的氛围感。

设计上避免两个极端：
- 避免过于花哨（抢了座位图本身的注意力）
- 避免过于冷淡（毕竟是消费场景，要有购买欲望的引导）

## 二、色彩方案

### 主色调

| 变量 | 色值 | 用途 |
|------|------|------|
| `--bg` | `#070a12` | 主背景，深蓝黑，模拟影厅暗场 |
| `--panel` | `#111725` | 面板底色（半透明玻璃态） |
| `--line` | `#29344b` | 分割线、边框 |
| `--text` | `#f5f7fb` | 主文字（高对比白） |
| `--muted` | `#94a0b8` | 次要文字 |

### 强调色

| 变量 | 色值 | 用途 |
|------|------|------|
| `--cyan` | `#65e7ff` | 电光青，主强调色（推荐、激活态） |
| `--blue` | `#6579ff` | 电光蓝，次强调（按钮渐变） |

### 状态色（座位语义）

| 变量 | 色值 | 语义 |
|------|------|------|
| `--green` | `#32d583` | 空座（可选） |
| `--yellow` | `#fdbf47` | 已选（待确认） |
| `--red` | `#f35f67` | 已售（不可选） |
| `--purple` | `#a77dff` | 智能推荐 |

### 色彩选择的考量

- **深蓝黑背景**：模拟影院熄灯后的环境，让明亮的座位色块在暗背景上高对比跳出，符合"信息焦点=座位"的优先级。
- **电光青/蓝作强调**：传达科技感和未来感，区别于传统购票 App 的大红大黄，更显克制高级。
- **状态色用语义明确的纯色**：绿=通行、黄=注意、红=禁止，符合通用认知，降低理解成本。
- **色盲友好模式**：把红绿替换成蓝紫，保证色觉障碍用户也能区分状态。

## 三、布局设计

### 整体结构

采用 **左主右辅** 的双栏布局（PC 端）：

```
┌─────────────────────────────────────────────┐
│  顶部导航（品牌 + 视图切换 + 账户）            │
├──────────────────────────┬──────────────────┤
│                          │  右侧侧栏         │
│   左侧：Canvas 座位图      │  ① 输入需求       │
│   （主视觉，最大区域）      │  ② 确认座位       │
│                          │  ③ 提交订单       │
└──────────────────────────┴──────────────────┘
```

**为什么这样布局**：
- 座位图是核心信息，占最大面积，视觉重心明确
- 右侧三步流程纵向排列，引导用户从上到下完成操作（符合阅读习惯）
- 操作区与视觉区分离，避免用户在选座时被表单干扰

### 响应式适配

| 断点 | 布局变化 |
|------|---------|
| ≥1050px（PC） | 双栏：Canvas 左 + 侧栏右 |
| 700-1050px（平板） | 单栏，侧栏变两列网格 |
| ≤700px（手机） | 完全单栏，Canvas 全宽，侧栏堆叠到下方 |

Canvas 在所有尺寸下都自适应宽高，并按 DPR 重设分辨率避免模糊。

### 卡片与层次

- 所有模块用统一的 `.card` 容器：半透明渐变底 + 1px 边框 + 大圆角（18px）+ 深阴影
- 玻璃态（backdrop-filter）在弹窗上使用，营造悬浮感
- 层次靠阴影和边框，不用强烈色块分割，保持整体统一

## 四、字体选择

| 场景 | 字体 | 字号 |
|------|------|------|
| 正文/UI | `Inter` + `Microsoft YaHei`（中英混排） | 16px 基准 |
| 标题 | 同上，加粗 | 17-25px |
| 辅助说明 | 同上 | 11-13px（`--muted` 色） |
| Canvas 内座位号 | `Arial`（Canvas 渲染稳定） | 7-9px（按厅大小） |

**选择考量**：
- Inter 是为屏幕优化的现代无衬线字体，字形清晰，适合 UI
- 中文回退到微软雅黑，保证 Windows 端显示效果
- Canvas 内文字用 Arial 而非 Inter，因为 Canvas 文字渲染对字体可用性敏感，Arial 兼容性最稳
- 大字体模式下基准放大到 19px，所有元素用 `rem`/相对单位，整体等比缩放

## 五、动效与反馈

| 场景 | 动效 |
|------|------|
| 步骤完成 | 进度条渐变填充 + 微光 |
| 按钮悬停 | 背景色过渡 |
| 推荐座位 | 紫色高亮（区别于普通选中） |
| 操作反馈 | 底部 toast 滑入 + 可选语音 |
| 模式切换 | CSS 过渡，无突兀跳变 |

动效遵循 **"有意义才动"** 原则——只用于反馈用户操作或引导注意力，不做纯装饰动画。

---

## 六、无障碍视觉设计

| 模式 | 视觉调整 |
|------|---------|
| 大字体 | 基准字号 +18%，Canvas 座位号同步放大 |
| 高对比度 | 背景纯黑、文字纯白、边框加粗 |
| 色盲友好 | 红绿→蓝紫，黄保留，所有状态可区分 |

无障碍不是事后补丁，而是设计时就用 CSS 变量体系承载，切换模式只需改变量值，Canvas 颜色也通过 `getComputedStyle` 同步读取。

---

*视觉方案的最终目标是：让用户在选座时既感受到影院的氛围（沉浸），又能快速看清信息（清晰），并且不会因为界面本身分心（克制）。*
